# 🌌 Cosmic Problem App

A modern, dark-themed UI for space, AI, and physics enthusiasts to discuss complex cosmic questions. Built using **Flutter** and translated directly from custom Figma designs.

---

## ✨ Features

- **Home Feed:** Story previews, category filters, and trending problem cards.
- **Problem Creation:** Structured problem posting with attachment options.
- **Community Explore:** Tag clouds and category discovery.
- **Messaging:** Direct messaging interface with online indicators and unread badges.
- **User Profiles:** Stats, active story previews, and custom achievement badges.
- **Activity Hub:** Categorized notifications with unread status tracking.
